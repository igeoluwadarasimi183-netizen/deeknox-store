About DEEKNOX Store

DEEKNOX Store is a beginner web-development project created to practise building a multi-page online shop.

This demo brings together HTML, CSS and JavaScript. It shows how pages can share one stylesheet and one JavaScript file.

Demo notice: This is a learning website, not a live shop. It does not accept real orders or payments.
